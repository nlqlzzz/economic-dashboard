最終更新: 2026-09-02

## Investment Roadmap

### Phase 1: 既存データを投資判断につなげる

- レジーム別リターン分析: 現在と同一・近似するマクロ局面後の1・3・6か月パフォーマンス、平均、中央値、上昇確率、サンプル数を表示。
- 相関変化検知: 20日・60日相関、1・3か月前との差、過去5年percentile、急変アラートを表示。
- 投資テーマ別ビュー: 半導体、米国株、日本株、円、Goldの既存情報をテーマ単位で再構成。

### Phase 2: 過去データから期待値を見る

- イベント前後分析: CPI、雇用統計、FOMC、PCEの当日・翌営業日・5・20営業日後を集計。
- 過去類似局面検索: 各時点までのデータで標準化した日次特徴量とマクロ評価の距離を使い、近接日を除いた類似局面、その後の1・5・20営業日実績、特徴量寄与、サンプル数を表示。

### Phase 3: 情報を一つの投資仮説へまとめる

- Market Stress Score: VIX、株価の実現ボラ・下落率、米10年金利変化、為替ボラを過去5年percentileへ変換し、0〜100のスコア、寄与、サンプル数、データカバレッジを表示。
- 市場変動の要因仮説: ストレス構成項目、直近変化、米国マクロ評価から、整合する観測・反対材料・観測数を伴う上位3候補をルールベースで表示。

## Japan Semiconductor Cycle Roadmap

1. データ取得方法の調査・設計
   - METI鉱工業指数の2020年基準Excel、分類コード、季節調整区分、改定リスク、公表日基準のバックテスト方針を確認。
2. 電子部品・デバイス工業4指標
   - 生産・出荷・在庫・在庫率の最新値、前月比、前年比、3か月移動平均、対象年月、データ出所を半導体テーマ内に表示。
3. 半導体在庫循環マップ
   - 出荷前年比×在庫前年比の24か月軌跡と最新局面候補を表示。
4. 半導体製造装置受注
   - 内閣府の「電子計算機等」（半導体製造装置を含む）を補助系列として使用し、単月値より3か月平均と前年比を重視する構成を実装。
5. 半導体テーマ統合
   - 日本半導体株、SOX、NASDAQ、米10年金利、VIX、USD/JPYと実体統計をMarket / Relative・Correlation / Japan Fundamental Cycleとして同じテーマ内に整理。
6. 過去検証
   - 電デバ出荷・在庫前年比と電子計算機等受注3か月平均前年比について、利用可能日以降の株価だけを使うリード・ラグ相関と条件付き将来リターンを表示。
   - 履歴公表日がないため対象月の2か月後の月初を保守的な利用可能日とし、改定後データによる暫定検証であること、サンプル数、低標本警告、非因果・非助言を明示。

## Semiconductor Roadmap

1. Global Demand基盤
   - 台湾経済部の電子製品・情報通信製品輸出受注を公式CSVから取得し、金額、前年比、3か月平均、3か月平均前年比、3〜6か月モメンタムを表示。
   - 韓国関税庁の半導体輸出について、1〜10日速報、1〜20日速報、月次を公式発表から区別して取得する構造を追加。
   - 台湾・韓国を地域、系列、対象期間、公表日、取得日時、公表段階、部分期間、通貨、Derived判定、データVintageを持つ共通形式へ正規化。
2. 半導体テーマ統合
   - Semiconductor Snapshot → Market → Global Demand → Japan Cycle → Historical Validationの情報階層へ拡張。
   - 海外半導体UIを専用モジュールへ分離し、片国の取得失敗時も市場・他国・日本の表示を継続。
   - 台湾受注と実輸出の違い、韓国輸出額が数量と価格の積であること、速報と月次の違いを画面に明示。
   - 韓国の営業日調整は当年・前年同期の公式営業日数がそろう場合だけ計算し、Derived / 当アプリ計算値として分離。
3. Global Semiconductor Demand Pulse
   - 台湾受注、韓国輸出、日本の生産・出荷・在庫・在庫率・設備投資を地域別に判定し、改善・悪化・欠損系列を開示。
   - Global判定は最低2地域を必要とし、3地域中のcoverageを表示。1地域以下ではLimited Dataとして地域別状態だけを表示。
4. Price vs Fundamentals
   - SOXの1・3・6か月モメンタムとGlobal Demandを比較し、同方向、期待先行の可能性、実需が相対的に強い状態、シグナル混在を説明表示。
   - 売買・割安・バブル等の断定表現や0〜100の統合スコアを使用しない。
5. 海外Historical Validation基盤
   - 台湾・韓国の月次系列について、公表日前の価格を基準値へ使わない1・3・6か月後リターン分析を追加。
   - 実公表日付き観測だけの厳密検証を主表示とし、公表日不明データへ明示的な利用可能日を付ける暫定検証は別表示。
   - 韓国1〜10日・1〜20日速報は月次履歴へ接続せず、現況判断専用として長期バックテストから除外。
   - 平均、中央値、上昇確率、四分位、最悪・最良、サンプル数と段階的な低標本警告を表示。
6. 韓国月次半導体輸出のデータ品質改善
   - 産業通商部の公式記事一覧にあるJavaScript形式の詳細リンクを探索し、ICT輸出入動向本文から半導体輸出額、公式前年比、対象月、登録日、公表段階を取得。
   - 公式前年比と実公表日がそろう月次履歴を現在値・速報と共通形式で統合し、前年比のない月次行は有効な履歴がある場合にPulse判定から除外。
   - 1〜10日・1〜20日速報は現況判断用の部分期間として維持し、月次履歴や厳密検証へ混入させない。

## Technical Roadmap

1. 自動テスト・継続的インテグレーション
   - GitHub Actionsで単体テスト、Python構文検査、依存関係の整合性確認をPRとmain更新ごとに実行。
   - 外部データ取得やSecretsに依存しないテストを標準化。
2. 経済イベントカレンダーの保守性
   - BLS・FRBの公式日程を設定ファイルへ分離し、スキーマ、出所、重複、日時順、収録期限、日本時間変換を検証。
   - 画面の収録期限を設定から生成し、更新手順を文書化。
3. データ鮮度の異常表示
   - 営業日次・暦日次・月次の更新頻度と猶予を定義し、想定より古い系列を警告。
4. データ取得の信頼性・診断
   - 一時的な通信失敗の再試行、取得失敗時の診断情報、取得時刻・試行回数を表示。
5. 画面構成・モバイル表示
   - 本文を4タブへ分割し、390×844px相当で主要UIの余白と横あふれを確認。
