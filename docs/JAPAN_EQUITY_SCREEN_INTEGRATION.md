# 日本株分析 画面統合

最終更新: 2026-09-13

## 目的

初回表示からCore20の一銘柄を選び、**業績 → 評価水準 → 価格の反応 → リスク**の順に判断材料を確認できるようにする。市場感応度、マクロ感応度、市場調整後リターン、Core20 Anchor、観測後相関、回帰は補助分析として残す。

## 旧画面からの移動先

| 旧表示 | 新しい表示先 |
|---|---|
| 投資テーマ > 日本株 > Japan Core 20 | 上部ナビゲーション > 日本株 |
| Japan Core 20 Snapshot / Market Map / Sector / Theme | 日本株 > Core20一覧 |
| Macro Sensitivityの銘柄選択 | 日本株上部の共通銘柄選択へ統合 |
| Stock Detailの銘柄選択 | 日本株上部の共通銘柄選択へ統合 |
| Fundamentals / Earnings | 銘柄分析 > ① 業績 |
| Performance / TOPIX Relative | 銘柄分析 > ③ 価格の反応 |
| Market Exposure / Macro / Residual / Anchor / Diagnostics | 銘柄分析 > 補助分析 |

市場概況、米国経済イベント、ストレス・相関等の分析、半導体を含む投資テーマは上部ナビゲーションに独立した入口を残す。投資テーマで日本株を選んだ場合は、新しい日本株画面を案内し、Core20分析を二重表示しない。

## 操作

1. 初回表示の「日本株」で「分析する銘柄」を選ぶ。
2. 最新決算の対象期・開示日、会社予想と実績の区別を確認する。
3. 評価水準が未評価の場合は、価格騰落を割安・割高の代用にしない。
4. 絶対リターンとTOPIX連動ETF比、および共通の比較開始日・終了日を確認する。
5. 投資判断上の確認事項とデータ上の制約を区別して読む。
6. 必要な場合だけ補助分析またはCore20一覧を開く。

選択値は`st.session_state["japan_selected_ticker"]`で共有し、業績・価格・リスク・補助分析が同じ銘柄を参照する。価格を取得できない銘柄も選択肢から消さない。

## データ依存と失敗時の扱い

- 価格はYahoo Financeの`auto_adjust=True`による調整後終値。価格品質、鮮度、履歴不足、取得不可を区別する。
- 決算はJ-Quantsの正規化済みFinancial Summary。最新対象期にない指標を古い期から補完しない。
- 価格が利用不可でも取得済みの決算を表示し、決算が利用不可でも価格と比較可能なリターンを表示する。
- データ不足は投資リスクと別枠で表示し、低リスクとは扱わない。
- 詳細な取得エラーは折りたたみへ置き、主画面では短い状態を表示する。

## 評価水準の制約

現在の信頼できる共通データだけでは、対象期・価格基準日・株式数・株式分割をそろえたPER/PBRを全Core20へ表示できない。そのため評価水準は短く「未評価」と表示する。今後、公式データの定義とcoverageを診断した後に別PRで実装可否を判断する。

## 維持する分析条件

- PR69の赤字・ゼロを含む業績比較、EPS非差分化、対象期・会計定義の比較条件。
- PR70の円単位正規化、億円・兆円、EPS円表示。
- PR71の価格品質、公表時点、未満了除外、事後分析の説明。
- PR72の共通開始日・終了日、ペア品質処理、長期欠損の除外。
- 業績と価格を並べても、因果関係・織り込み・売買判断・予測力を断定しない。
