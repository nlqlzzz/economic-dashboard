# Japan Core 20 / Macro Sensitivity 実データ診断

実行日: 2026-09-04

診断期間: 2023-09-01〜2026-09-04

対象: Japan Core 20（半導体テーマ4銘柄は対象外）

## 1. Executive Summary

- 現行のRaw Returnベース表示には「市場と一緒に動いている」ことを確認する用途はあるが、銘柄固有のMacro Sensitivityを順位付けする主表示としては情報量が少ない。60日では20銘柄中11銘柄でTOPIXが絶対相関Top1、14銘柄でTop3だった。
- Simple Active Returnはβを1と固定した市場調整である。Primary Driverの期間安定性は10銘柄でRawより改善したが、βが1から離れる銘柄ではTOPIX成分が残るため、Residualの代用にはならなかった。
- 252日βによるResidual Returnは、TOPIXのTop1占有を60日で11銘柄から4銘柄へ低下させ、市場共通要因の除去には最も有効だった。ただし、Primary Driverの安定性改善は10銘柄にとどまり、全銘柄でマクロ関係が明瞭になるわけではない。
- 経済的な事前仮説と実データが比較的整合したのはINPEX（WTI）、MUFG（金利）、三菱地所（JGB 10Y）。トヨタはUSDJPY係数には一定の裏付けがある一方、短期相関と米国株Proxyの符号は不安定で、単純な「円安銘柄」表示だけでは不十分だった。
- 60日Top1がPrimary DriverだったのはRaw 2銘柄、Active 2銘柄、Residual 4銘柄だけだった。全系列の上位3件はEx post Correlationとして詳細表示に残せるが、主表示には向かない。
- リクルートHDは直近3か月で+52.9%、TOPIXは+4.1%、Active Returnは+48.9pt、252日β調整後の日次Residual累計も+28.1ptだった。TOPIX＋事前Primary Driverの調整済みR²は5.6%から4.9%へ低下し、今回の市場・マクロ系列では上昇の大部分を説明できない。
- 本番設計を変える前に、`1306.T` の企業行動・異常値検査が必要である。Yahoo Finance系列に2026-03-30〜31の約10分の1価格が混入し、未補正ではβ・Active・Residualが無意味になった。本診断だけはその2日を除外した。

## 2. Data / Methodology

### データ

- Core 20とTOPIX Proxy: Yahoo Financeの調整後終値。TOPIXはTOPIX連動ETF `1306.T` であり指数そのものではない。
- USDJPY、SOX、NASDAQ、S&P 500、WTI、VIX、上海総合: 既存のYahoo Finance取得設定。
- JGB 10Y: 既存の財務省取得処理。
- UST 10Y: 既存のFRED取得処理。
- Core 20は20/20銘柄、Macroは10/10系列を取得できた。価格系列は2023-09-01〜2026-09-04、JGBは2026-08-31、USTと米国株指数は2026-09-02〜03までである。

### リターンの定義

- **Raw Return**: 個別株の日次騰落率。
- **Simple Active Return**: 個別株リターン − TOPIX ETFリターン。Risk Free Rate控除後のExcess Returnではない。
- **Residual Return**: `Stock = α + β × TOPIX ETF + ε` を最新252共通観測で推定したε。目的はCAPM αの推定ではなく、市場共通要因の診断的除去である。
- 金利は日次騰落率ではなく日次変化幅を使用した。他の系列は日次騰落率を使用した。
- 相関は同時点の20/60/120/252営業日。先行性を検証するものではない。

### βとデータ品質

主分析は推定の安定性を優先して252日βを採用し、120日βも感応度として確認した。例えばINPEXは252日β 0.36に対して120日β -0.13、日立は1.12対0.69であり、β自体が期間依存となる銘柄がある。一方、MUFGは1.09対0.95、三菱地所は1.06対0.93と比較的近かった。

`1306.T` には2026-03-30〜31の価格水準が前後日の約10分の1になる孤立区間があった。日次リターンは約-90%と+948%となり、全回帰を破壊する。本診断では「前後に25%超の逆方向変化があり、区間をまたぐ変化は25%未満」の2日だけを除外した。この補正は本番ローダーには反映していない。

## 6. Correlation Stability

- Rawの60日Top1がPrimary Proxyでない銘柄は18/20だった。Activeは18/20、Residualでも16/20であり、単一期間の無差別Top1は事前仮説とほぼ一致しない。
- 20/60/120日の全期間でTop3に残った系列数は、1銘柄平均でRaw約1.35、Active約1.30、Residual約0.90だった。Residual化すると市場要因の代わりに短期ノイズが上位へ入り、ランキング自体はむしろ入れ替わりやすい。
- 20/60/120日のPrimary Proxy符号が一致した銘柄はResidualで14/20だったが、絶対相関が小さいまま符号だけ一致する例を含む。符号一致だけで「安定」と表示してはいけない。
- 60日を単独表示すると、20日ノイズよりは安定するが120日で消える関係を見落とす。120日を主軸、60日を現在の変化、20日を短期参考として併記するのが妥当である。

## 7. Case Studies

### INPEX

WTI相関はRawで+0.50 / +0.43 / +0.35、Residualで+0.51 / +0.44 / +0.36（20/60/120日）。市場調整後も維持され、USDJPYもResidualで+0.48 / +0.28 / +0.31だった。TOPIXのみの調整済みR² 4.1%に対し、WTI・USDJPY追加後は16.0%（+11.9pt）。今回最も明瞭なMacro Sensitivityである。ただし120日βが-0.13、252日βが+0.36と不安定で、直近3か月Residual累計-7.9ptの解釈には注意が必要である。

### MUFG

JGB 10YはRawで期間により符号が変わったが、Residualでは+0.29 / +0.22 / +0.25へ揃った。UST 10Yは+0.17〜+0.21（60〜252日）だが20日は-0.28。回帰ではTOPIXのみの調整済みR² 51.7%、金利・USDJPY追加後54.9%（+3.2pt）。JGB係数のt値3.73、USTは1.98、USDJPYは弱かった。市場調整が金利感応度の可視化に有効だった例である。

### 三菱地所

JGB 10YはRawで-0.43 / -0.33 / -0.43、Residualでも-0.45 / -0.10 / -0.24。方向は一貫して負だが、市場調整後の60日強度は弱まった。TOPIXのみの調整済みR² 37.6%からJGB追加で39.5%（+1.9pt）、JGB係数のt値は-3.01。符号の経済的妥当性は確認できるが、効果量はINPEXより小さい。

### トヨタ

USDJPYはRawで-0.08 / +0.09 / -0.03と不安定だが、Residualでは+0.05 / +0.18 / +0.17となった。252日回帰のUSDJPY係数は正でt値3.02。一方、S&P 500とのResidual相関は-0.67 / -0.43 / -0.21で、回帰係数は負かつt値-1.42だった。米国市場Proxyの短期負相関を構造的Driverと解釈すべきではない。

### その他

フジクラのSOX相関はResidualで+0.43 / +0.13 / +0.10と短期ほど強く、期間依存。信越化学はRawのSOX相関が市場調整後に大きく低下し、共通株式市場要因の寄与が大きい。関西電力はWTIが正相関だが回帰R²改善は+0.5ptにとどまる。

Primary ProxyのS&P 500とのResidual相関は-0.07 / -0.17 / -0.07、USDJPYは-0.06 / +0.05 / +0.00で、20/60/120日のいずれも弱い。TOPIXのみの調整済みR²は5.6%、S&P 500・USDJPY追加後は4.9%へ低下した。60日Ex post Top DriverはVIXだが、Primary Driverではなく、期間間で安定していない。

したがって、今回の既存系列では上昇を十分説明できず、**Idiosyncratic / Macro-unexplained componentが大きい**と判断する。これは決算・企業材料が原因だと断定するものではなく、今回の説明変数集合では説明できないという限定的な結論である。

## 10. Dashboard Implications

A. Raw Returnは市場共通要因を見る補助表示として維持できるが、Macro Sensitivityの主軸にはしない。

B. TOPIXは全系列ランキングから除外し、別枠の「Market β / Market correlation」として表示する。

C. Active ReturnはTOPIX比パフォーマンスには適切だが、感応度分析の中心にはしない。

D. Residual ReturnをMacro Sensitivityの中心候補とする。ただしβ期間・異常値・最低標本数を明示する。

E. 全系列Top3は折りたたみ式のEx post参考へ格下げする。

F. 主表示はEx ante Primary Driverを中心とし、実測20/60/120日相関と符号安定性を見せる。

G. UI中心は120日、補助に60日、20日は短期ノイズとして詳細表示する。252日はβ推定・長期参考に使う。

H. 安定性表示には価値がある。符号一致だけでなく、強度持続・期間レンジ・観測数を併記する。

I. `Macro-consistent / Mixed / Macro-unexplained` は有用。リクルートのようなケースを無理な相関解釈から守れる。

J. 全20銘柄を計算対象には維持しつつ、明瞭な銘柄だけを強調し、Lowは「説明力限定」と表示する。

## 11. Recommended Next Design

1. まずTOPIX Proxyの日次リターンに企業行動・異常値検査を追加し、補正不能時はResidualをUnavailableにする。
2. 「Market Exposure」と「Macro Drivers」を分離する。Market Exposureにはβ・TOPIX相関・Active Return、Macro DriversにはResidual対Primary Driverを置く。
3. Primary Driverカードは120日相関を主値、60日を現在方向、20日を短期参考とし、3期間の符号・強度の安定性を文章で示す。
4. Top3は「データを見た後の相関上位（Ex post）」と明記し、Primary Driverへ自動昇格させない。
5. 252日βを既定候補とし、120日βとの差が大きい場合は「β不安定」と警告する。ローリングβの採用は別診断後に判断する。
6. Macro Explainabilityは固定点数にせず、Primary Driver安定性、回帰R²改善、Residualの大きさを根拠としてHigh / Medium / LowまたはMacro-unexplainedを説明する。
7. INPEX、MUFG、三菱地所を先行導入候補、トヨタを要注意の検証候補とし、表示設計を確認してから全銘柄へ展開する。

## 12. Limitations

- 結果は2026-09-04時点の最新取得データに依存し、期間をずらすと変化する。
- 日米市場の取引時間差・休日差を単純な日付結合で扱っており、非同期取引の影響を除いていない。
- TOPIXはETF Proxyであり、指数・配当込み指数ではない。今回見つかった異常区間は診断限定で除外した。
- Residualは最新252日で固定推定したin-sample残差で、時点ごとのローリング推定や将来検証ではない。
- 120日と252日のβ差が大きい銘柄があり、単一βは構造変化を捉えない。
- Primary Driverに実データProxyがない概念があり、JR東日本などは十分に検証できない。
- 企業決算、業績修正、ニュース、セクター指数、リスクフリーレートは使用していない。
- 相関・回帰は同時点関係であり、先行指標性、因果関係、売買有効性を検証していない。
- StabilityおよびMacro Explainabilityは診断用であり、本番スコアではない。
