# 韓国ICT輸出入動向 公式記事archive診断

調査日: 2026-09-19

判定: **NO-GO**

## 1. 調査目的

KOSIS / ITSTAT経路を厳密Historical Validationに利用できないとした[`KOREA_SEMICONDUCTOR_HISTORY_DIAGNOSTIC.md`](KOREA_SEMICONDUCTOR_HISTORY_DIAGNOSTIC.md)の後続として、2023年6月以前の科学技術情報通信部（MSIT）／産業通商部の公式ICT輸出入動向記事から、対象月、半導体輸出額、公式前年比、実公表日を復元できるかを最後に限定調査した。

本診断では本番loader、UI、Historical Validationを変更せず、大量取得も行っていない。

## 2. 現行取得経路との関係

現行の`data_loader.py`は、産業通商部の現行報道資料一覧を日付条件付きで最大4ページ検索し、`article.view(article_id)`から次のURLを組み立てる。

```text
https://www.motir.go.kr/kor/article/ATCL3f49a5a8c/{article_id}/view
```

タイトルに`ICT`または`정보통신`を含む記事が見つかるとICT記事だけを取得し、`parse_korea_ict_monthly_release`がHTML本文から次を抽出する。

- タイトル中の対象年月
- `반도체 : N억불, R%`形式の半導体輸出額・公式前年比
- `등록일 YYYY-MM-DD`形式の記事登録日

live取得済みの連続履歴は2023年6月以降である。今回調査した旧MSIT記事はページ構造とarchiveが異なる。

## 3. 確認した公式archive

### 3.1 MSIT統合検索

[科学技術情報通信部の統合検索](https://www.msit.go.kr/search/ko/searchKo.do)には、検索結果ごとに記事タイトル、詳細URL、登録日時、添付ファイル名が表示される。2023年4月・5月についてlive確認できた。

詳細URLの規則は次のとおりで、記事固有値は`nttSeqNo`である。

```text
https://www.msit.go.kr/bbs/view.do?sCode=user&mId=307&mPid=208&bbsSeqNo=94&nttSeqNo={article_id}
```

詳細ページにはタイトル、担当部署、HWPX、ODT、文書viewerが残る。一方、登録日時は詳細ページ本文にはなく、統合検索結果にだけ表示された。

### 3.2 MSIT旧報道資料一覧

詳細ページの「一覧」導線は調査時にシステム点検画面となり、過去一覧を連続走査できなかった。したがって統合検索以外の安定した公式一覧endpointは**未確認**である。

### 3.3 IITP政策・統計資料

[情報通信企画評価院（IITP）の政策・統計資料](https://iitp.kr/kr/1/knowledge/statisticsView.it?identifier=02-008-230823-000001&masterCode=publication&searClassCode=K_STAT_01)には、ICT輸出入動向の要約とMSIT原記事へのリンクが残る例がある。ただし旧URLは現在のIITPトップへredirectされる場合があり、IITPの「発行日」はMSITの記事登録日より後の再掲日となり得る。厳密検証の`release_date`には代用できない。

## 4. 代表月の確認結果

同一サイト・同一語の反復探索を避け、主対象から5か月だけを確認した。

2023年4月・5月の記事登録日時は、対象月の翌月に公式サイトへ登録された実時刻として取得できる。ただし、この結果だけで2021年〜2023年5月の連続した月別archiveが存在するとは判断できない。

「該当記事なし」は、対象記事が存在しなかったという断定ではない。現行統合検索に移管・索引されていない、旧サイトだけにあった、または削除された可能性を区別できないため、**未確認**とする。いずれの場合も自動取得可能な現行公式archiveとしては利用できない。

## 5. 半導体輸出額・前年比

2023年4月・5月の詳細ページには当時の公式HWPX添付が残り、文書viewerとODT downloadの導線も存在する。しかし数値は通常の詳細ページHTML本文に展開されず、調査環境では文書viewer本文と直接downloadを安定して機械読取できなかった。

したがって、次を区別する。

- 記事と当時添付の現存: **live確認済み**
- 記事登録日時: **live確認済み**
- 半導体輸出額・前年比が通常HTML本文に存在: **存在しない**
- 添付からの数値機械抽出: **未確認**
- 2021年〜2023年5月の各月で同じ4項目を復元: **確認できない**

添付ファイル名の日付を`release_date`として推定せず、統合検索が示す登録日時だけを実公表日の候補とする。

## 6. 現行parseロジックの適合性

代表5か月のうち、現行`parse_korea_ict_monthly_release`をそのまま使えると確認できた月は0件だった。

- 2023年4月・5月: タイトルは一致するが、半導体輸出額・前年比が詳細ページHTMLではなく添付にある。また詳細ページHTMLに`등록일`がない
- 2023年1月、2022年6月、2021年1月: 現行公式検索から記事URL自体を取得できない

利用するには、MSIT統合検索専用discovery、登録日時の対応付け、HWPX / ODT download、文書parser、添付schema変更検知が新たに必要になる。これは現行HTML parserへの小さなURL追加ではない。

## 7. 定義の整合性

2023年4月・5月の記事は、科学技術情報通信部の情報通信産業政策課が公表した「情報通信産業（ICT）輸出入動向」であり、現行の産業通商部ICT記事と同じ月次ICT輸出統計の公表系列である。KOSIS診断で確認した通関ベースICT統計とも統計ファミリーは整合する。

ただし今回、添付中の半導体値を機械抽出して既存行と照合できなかったため、個々の値・丸め・公表段階の一致は**未確認**である。

## 8. 自動取得可能性と運用負荷

2023年4月・5月だけなら、統合検索結果からURLと登録日時を取得し、添付を別parserで処理する実装候補はある。しかし主対象期間全体では次の問題が残る。

- 2021年・2022年と2023年初の公式記事が現行検索で発見できない
- 旧報道資料一覧が連続走査できない
- 登録日時が詳細ページではなく検索index依存
- 値・前年比がHWPX / ODT添付依存
- 文書download / viewerが通常のGETだけでは安定して取得できない
- MSIT、MOTIRでURL、HTML、記事ID、添付形式が異なる

2か月程度の追加候補のために検索indexと文書変換基盤へ依存する専用loaderを維持する運用負荷は、厳密検証の標本増加に見合わない。

## 9. 判定

最終判定は **NO-GO**。

2023年4月・5月については実公表日時と当時添付の公式ペアが残るが、主対象の2021年〜2023年5月を連続して発見できず、当時値・公式前年比の自動復元も確認できない。現行parserは代表月すべてでそのまま利用できず、実装・運用負荷に対して延長できる可能性が最大でもごく短い。

したがって、KOSIS / ITSTAT経路と公式記事archive経路の両方を打ち切り、韓国半導体輸出の厳密Historical Validationは現行の2023年6月開始を維持する。推定公表日、検索index日付の補完、非公式転載、改定後DB値は使用しない。

## 10. 終了条件と次の一手

韓国長期履歴拡張は本診断で終了する。同じMSIT検索や旧記事探索を反復しない。

今後、公式機関が2021年以降の全月について、記事登録日時と当時公表資料を対応付けた機械可読archiveを新たに公開した場合だけ再開できる。それまではSemiconductor Roadmapの次項である台湾データ品質改善へ進む。
